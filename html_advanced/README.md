# ALU Web Development - HTML Advanced

This project implements the HTML structure of a landing page from a Figma
design file, focusing purely on semantic HTML with no CSS or styling.

![Design preview](https://placehold.co/800x400?text=Landing+Page+Design)

## Structure
The page includes a header with navigation, a hero banner, a quote section,
a videos list, a membership section, an FAQ, and a footer.
